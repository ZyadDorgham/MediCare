# 🏥 MediCare Dashboard

A modern and responsive **Medical Management Dashboard** built with **React.js** and **Vite**.

MediCare Dashboard provides a clean interface for managing doctors and appointments, with a focus on reusable components, state management, local data persistence, filtering, searching, and responsive UI design.

🔗 **Live Demo:** https://medi-care-dashboard.vercel.app/

---

## 📌 Overview

**MediCare Dashboard** is a frontend medical administration system designed to simplify the management of doctors and appointments.

The project was built as a practical React application to apply modern frontend concepts such as:

* Component-based architecture
* React Hooks
* State management
* Data filtering and searching
* Local Storage
* Reusable UI components
* Responsive design
* CRUD operations
* Form validation
* Performance optimization with `useMemo`

---

## ✨ Features

### 👨‍⚕️ Doctor Management

* Add new doctors
* Display doctors in organized cards/table layouts
* Search doctors
* Filter doctors
* Delete doctors
* Display doctor statistics
* Manage doctor specialties and departments

### 📅 Appointment Management

* Create new appointments
* Select doctors from the available doctors
* Manage appointment information
* Search appointments
* Filter appointment data
* Display appointment statistics
* View appointment details
* Delete appointments

### 💾 Data Persistence

The application uses **Local Storage** to persist doctors and appointments.

This means data remains available even after refreshing the browser.

### 📱 Responsive Design

The dashboard is designed to work across different screen sizes:

* Desktop
* Laptop
* Tablet
* Mobile

### ⚡ Performance

The project uses React optimization techniques such as:

* `useMemo`
* Efficient state updates
* Reusable components

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project

```bash
cd MediCare-Dashboard
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available locally through the Vite development server.

---

## 🏗️ Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
